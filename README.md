# Email Selector Tool

A simple tool to send bulk emails using Gmail.

## How to Use
1. Upload your customer CSV file
2. Write your email subject and message
3. Select customers (25 at a time)
4. Click "Gmail Mein Open Karein"
5. Gmail will open with emails in BCC — just hit Send!

## CSV Format
name, email
Ali Ahmed, ali@example.com
Sara Khan, sara@example.com

## Features
- CSV file upload
- Select customers by range (1-25, 26-50, etc)
- Opens Gmail with BCC filled automatically
- No server needed — works in browser
